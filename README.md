# Marionette Light

Control trace — who deploys, admins, signs. Not money flow.

Paste seed contracts, **Trace**, then **Expand** a hand or **Other chains**. Visitors bring their own Etherscan API key (stored in the browser only).

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:8766

## Vs Marionette (full)

Light has no Neo4j, no Cypher export, no Force layout. Same resolve / expand / other-chains core.
