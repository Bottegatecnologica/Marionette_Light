Truth model

Source of truth

Edges come only from the local resolver via Etherscan API v2. The UI never invents relationships.

Verified on-chain

  • DEPLOYED — getcontractcreation; Expand keeps CREATE only if creator matches the hand.
  • ADMIN_OF owner / proxy — live owner() and EIP-1967 / ZOS admin slots.
  • ADMIN_OF DEFAULT_ADMIN — RoleGranted/Revoked net and live hasRole.
  • SIGNER_OF — Safe getOwners() with strict ABI decode.
  • IMPLEMENTATION_OF — proxy impl slot (node kind Contract, not a hand).
  • SAME_AS — same address across chains as nearest-neighbor path A—B—C.

Heuristic

FUNDED is first inbound ETH — context only, labeled heuristic, not counted in Hands, not Expandable.

False negatives

Rate limits, custom Ownable, Timelock-only admin, or non-Safe multisigs can omit real controllers. Missing edge ≠ proof of no control.
