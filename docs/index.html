Marionette Light

Tutorial — download & run

Marionette Light gira sul tuo PC: scarichi il codice, installi le dipendenze, apri il browser. Nessun account cloud. La chiave Etherscan resta nel browser.

1. Requisiti

  • Python 3.10+ — da python.org (su Windows spunta “Add Python to PATH”).
  • Connessione internet — le query vanno a Etherscan.
  • Chiave API Etherscan — gratuita su etherscan.io/apis (vale anche per le altre chain via API v2).

2. Installazione

Opzione A — ZIP

  1. Scarica lo ZIP e scompattalo.
  2. Apri un terminale dentro la cartella Marionette_Light-main.

Opzione B — Git

git clone https://github.com/Bottegatecnologica/Marionette_Light.git
cd Marionette_Light

Dipendenze e avvio

pip install -r requirements.txt
python app.py

Si apre il browser su http://127.0.0.1:8766. Lascia il terminale aperto mentre usi l’app.

Se la porta è occupata, chiudi un’altra istanza di Marionette oppure termina il processo Python precedente.

3. Chiave Etherscan

  1. Crea un account su Etherscan e genera una API key.
  2. Nell’app, campo Your Etherscan API key — la chiave resta solo in questo browser (localStorage).
  3. Non mettere la chiave nel codice né su GitHub.

Limiti free: molte richieste di fila possono rallentare lo scan; aspetta e riprova.

4. Primo utilizzo (flusso tipico)

  1. Chain — scegli la chain del contratto (es. Ethereum).
  2. Contract addresses — incolla uno o più indirizzi di contratti (uno per riga).
  3. Expand control tree — costruisce il grafo: deployer, owner, proxy admin, ruoli, Safe signer, ecc.
  4. Clicca un nodo “mano” (Controller / Signer / Safe) → Expand per cercare altri contratti controllati da quella mano.
  5. Look for plotted addresses on other chains — cerca le stesse EOA su altre chain. Spunta Include testnets se ti servono Sepolia & co.
  6. Tab Hands — elenco mani; filtra con i chip della chain.
  7. Export — salva il JSON del grafo; Import per riprenderlo dopo.

5. Interfaccia in breve

  • Layout — ogni chain è una colonna; i contratti seed stanno in basso, le mani sopra (come fili di una marionetta).
  • Pannelli — frecce ai lati per chiudere sinistra/destra e allargare il canvas.
  • Search (in alto) — trova un address già plottato.
  • Selection — Copy, Explorer, Expand; tab Edges / Hands.
  • SAME_AS (archi blu tratteggiati) — stesso address su un’altra chain.
  • Doppio click su un nodo/edge → Expand.

6. Cosa significano i link

  • DEPLOYED — lo ha deployato (Etherscan creation).
  • ADMIN_OF — owner / proxy admin / DEFAULT_ADMIN (verifiche on-chain).
  • SIGNER_OF — owner di un Safe.
  • IMPLEMENTATION_OF — implementation del proxy (non è una “mano”).
  • FUNDED — primo ETH in ingresso: solo contesto, non controllo.
  • SAME_AS — stesso indirizzo su un’altra chain.

7. Problemi comuni

pip non trovato

Reinstalla Python con “Add to PATH”, oppure usa py -m pip install -r requirements.txt.

La pagina non si apre

Controlla che il terminale dica Running on http://127.0.0.1:8766 e apri quell’URL a mano.

Nessun edge / poca roba

Chiave API errata, rate limit, o il contratto non espone owner() / Safe / slot proxy standard. Prova Expand sulla mano o un’altra chain.

Firewall / antivirus

Deve poter fare HTTPS verso api.etherscan.io.
