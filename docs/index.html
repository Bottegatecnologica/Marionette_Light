Marionette Light

Control — deploy, admin, sign.

Trace who pulls the strings on EVM infrastructure: deployers, owners, proxy admins, AccessControl, and Safe signers — across chains. Not a money-flow explorer.

Run locally GitHub Truth model How it works

Why Light

  • No Neo4j — paste contracts, use your Etherscan key, graph stays in the browser.
  • Marionette layout: seeds at the bottom, hands above, chains side by side.
  • Edges are live eth_call / Etherscan; FUNDED is marked heuristic.

Quick start

git clone https://github.com/Bottegatecnologica/Marionette_Light.git
cd Marionette_Light
pip install -r requirements.txt
python app.py
# → http://127.0.0.1:8766
